Проєкт: система управління проєктами всередині компанії з аналітикою прогресу та продуктивності.

Мета:
створити веб-застосунок, у якому компанія керує проєктами, учасниками та задачами, а також відстежує стан проєкту і вклад користувачів через прості та зрозумілі метрики.

---

## Основні сутності

* User
* Company
* CompanyMembership
* CompanyJoinRequest
* CompanyInvitation
* Project
* ProjectMembership
* ProjectRole
* Task

---

## Глобальні ролі (системні)

### Owner

* створює компанію
* приймає/відхиляє заявки на вступ
* запрошує користувачів у компанію
* створює проєкти
* призначає Project Manager
* додає користувачів до проєктів

### Project Manager

* керує призначеним проєктом
* створює задачі
* призначає виконавців
* змінює статуси задач
* створює project roles (назви ролей)
* призначає ролі учасникам проєкту
* переглядає метрики

### Worker

* бачить доступні проєкти
* бачить свої задачі
* змінює статус своїх задач

---

## Вступ до компанії

### Через заявку

* user створює запит на вступ
* Owner підтверджує або відхиляє

### Через інвайт

* Owner відправляє інвайт зареєстрованому користувачу
* user бачить інвайт у своєму акаунті
* user приймає або відхиляє

---

## Ролі

### Системні ролі

* Owner / Project Manager / Worker
* визначають доступи

### Project roles

* створюються PM як назви (tester, designer, frontend, backend)
* використовуються для організації команди
* НЕ впливають на permissions

---

## Проєкти

* належать компанії
* мають Project Manager
* мають список учасників
* мають project roles

---

## Задачі

Поля:

* title
* description
* status (To Do / In Progress / Done)
* assignee (user)
* project
* story_points (складність)
* deadline
* completed_at

---

## Метрики (ключова частина)

### 1. Project Health Score

Оцінка стану проєкту:

* базується на:

  * % виконаних задач
  * кількості прострочених задач
  * кількості активних задач без прогресу

Результат:

* одне значення або статус:

  * Good / Warning / Critical

---

### 2. User Progress Analytics

Аналіз вкладe користувача:

Для кожного user:

* кількість задач
* кількість завершених задач
* сумарні story_points
* story_points за період (тиждень / місяць)
* кількість задач виконаних вчасно
* кількість прострочених задач

Це НЕ оцінка для зарплати, а аналітика активності.

---

### 3. Загальна статистика

* всього задач
* виконано
* в процесі
* не почато

---

### 4. Візуалізація

* Burn-down chart
* Gantt chart

---

## Функціонал MVP

* авторизація користувача
* створення компанії
* вступ у компанію (заявки + інвайти)
* управління учасниками
* створення проєктів
* призначення PM
* додавання користувачів у проєкт
* створення project roles
* створення та редагування задач
* призначення виконавців
* зміна статусів задач
* dashboard з метриками

---

## Не входить у MVP

* мобільний застосунок
* гнучка система permissions (RBAC)
* email (SMTP)
* чат / коментарі
* вкладення
* real-time
* складні workflow задач
